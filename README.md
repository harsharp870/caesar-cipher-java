#Caesar Cipher Tool (Python GUI)

This project is a simple Caesar Cipher application built using Python and CustomTkinter. 
It allows users to encrypt and decrypt messages using a shift-based cipher.

---

##Features
- Encrypt text messages
- Decrypt encrypted messages
- User-friendly GUI
- Copy result to clipboard
---

##Technologies Used
- Python
- CustomTkinter
---

##How to Run
1. Install Python
2. Install required library:
   pip install customtkinter
3. Run the file:
   python caesar_cipher.py
---

##Working Principle
The Caesar Cipher is a substitution technique where each alphabet in the input text is shifted by a fixed number of positions.
##Example:
Input Message: SECURITY
Shift Value: 2
Encrypted Output: UGEWTKV[
